# IS ROWING FOR ME? — V7.7 REAL GEMINI RAG

This build uses **Google Gemini to generate every successful chatbot answer**.

## How the chatbot works

For each visitor question:

1. The Red Shed knowledge layer searches the indexed official Red Shed website content.
2. It retrieves the most relevant website excerpts for that exact question.
3. Those excerpts + the question + recent conversation are sent to Google Gemini.
4. Gemini generates a fresh conversational answer grounded in the Red Shed website material.
5. The chat displays the Gemini model, grounding mode, number of retrieved excerpts, and official source links.

There is **no silent rule-based answer pretending to be AI**.

The bundled Red Shed website snapshot is only a knowledge source used while the live website crawler refreshes. Answers are still generated by Gemini.

## Reliability

Primary AI connection:
- Google Gemini GenerateContent REST API
- Preferred model: `gemini-3.7-flash`

Automatic AI connection fallbacks:
- tries compatible Gemini Flash model IDs if a model endpoint is unavailable;
- retries temporary 429/5xx service errors;
- uses the Google Gen AI Python SDK as a second transport if the direct REST transport has a local compatibility problem.

The Red Shed crawler continues updating official public website knowledge in the background. A failed crawl cannot erase the last usable knowledge index.

## Setup

1. Run `PREPARE_DEMO_ONCE.command` once while connected to the internet.
2. Run `CONFIGURE_GEMINI.command`.
3. Put your fresh Gemini key after `GEMINI_API_KEY=` in the local `.env` file.
4. Save `.env`.
5. Run `START_V7_7.command`.
6. Keep the Terminal window open.
7. Use `http://127.0.0.1:8007`.

Never paste the API key into the website, GitHub, chat, screenshots, or source files.

## Verify before presenting

First run:

`CHECK_AI_READY.command`

You should see that the real Gemini API answered.

Then run:

`CHECK_DEMO_READY.command`

The final line should say:

`READY FOR DEMO — THE CHATBOT IS USING GEMINI AI + RED SHED WEBSITE KNOWLEDGE`

## What you should see in the website

A successful answer shows a line similar to:

`GEMINI AI · gemini-3.7-flash · LIVE RED SHED WEBSITE · 8 RETRIEVED EXCERPTS`

That line is deliberately visible so you can demonstrate that the response was generated by Gemini and grounded in Red Shed website knowledge.

## Refreshing Red Shed knowledge

The crawler automatically refreshes in the background while the server is running.

You can also use:

`REFRESH_RED_SHED_KNOWLEDGE.command`

The chat can continue using the last usable Red Shed knowledge while a live refresh is happening.
